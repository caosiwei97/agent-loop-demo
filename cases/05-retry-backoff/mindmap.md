# 指数退避重试
## 错误分类
### 可重试：429, 529, 408, ECONNRESET
### 不可重试：400, 401/403, 402
### 需要降级：连续多次 529
## 三种策略对比
### 固定间隔 → 重试风暴 ❌
### 指数退避 → 避免集中 ✅
### 退避+抖动 → 最优解 ✅✅
## 指数退避原理
### 间隔翻倍：500ms → 1s → 2s → 4s
### 上限：30,000ms
### 随机抖动打散请求时间
## 实战细节
### Retry-After 头优先于自算退避
### Claude Code: base 500ms, 最多 10 次
### 服务端比自己更清楚何时恢复
