# 哈希指纹检测
## 问题：怎么判断重复调用
### 比工具名 + 参数
### 参数可能很大，逐字比较太慢
## 解决方案：SHA256 指纹
### 指纹 = SHA256(工具名 + 稳定序列化(参数))
### 只取前 12 位
### O(1) 比较，高效存储
## 稳定序列化
### JavaScript 对象 key 顺序不确定
### {a:1, b:2} ≠ {b:2, a:1} (序列化后)
### 解决：Object.keys().sort() 排序
## 双重判定
### 调用指纹相同 + 结果指纹相同 = 无进展
### 调用指纹相同 + 结果指纹不同 = 有进展
### 比喻：客服每次说同样的话 = 死循环
