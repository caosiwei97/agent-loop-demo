# 边说边执行
## 核心优化
### 工具块一完成就立即执行
### 不等整条消息说完
### 工具执行与后续生成时间重叠
### 感知延迟减少 30-50%
## Pipelining 流水线
### 模型生成 tool_call_1
### 立即执行 Read A
### 同时模型继续生成 tool_call_2
### Read A 结果返回 + 执行 Read B
## 限制条件
### 不是所有工具都能并行
### 有依赖的工具必须串行
### 先读文件才能改文件
## streamText + maxSteps
### 自动多轮 Agent Loop
### maxSteps 限制最大轮次
### 防止无限循环
